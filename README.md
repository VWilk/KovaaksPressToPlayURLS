# KovaaK's Deep Link Generator

**Convert any KovaaK's sharecode or playlist URL into a one-click `steam://` deep link.** 
Instantly launch KovaaK's Aim Trainer directly into your chosen playlist without navigating the in-game menus.

## What is this?

This is a lightweight web tool that takes a KovaaK's sharecode (e.g., `KovaaKsCallingGearedWipe`) or a full website URL, extracts the playlist ID, and generates a **Steam URI** (`steam://run/824270/?action=jump-to-playlist;sharecode=...`).

Clicking the generated link automatically opens your Steam client, launches KovaaK's, and jumps straight to the specified playlist.
